## Hardware Monitoring
- [Autoruns](https://learn.microsoft.com/en-us/sysinternals/downloads/autoruns) - utility for Windows. Shows everything that starts automatically at system startup: programs, services, browser extensions. Helps find and disable what is unnecessary or malicious
- [Cores](https://github.com/Levminer/cores) - beautiful hardware monitoring app (CPU, GPU, RAM, temperatures) with an emphasis on visual design. Convenient for those who care about aesthetics, not just numbers
- [Glances](https://github.com/nicolargo/glances) - Cross-platform system monitor in Python: CPU/RAM/disks/network/processes/Docker in one TUI, web UI, API and export to StatsD/CSV; like top, for all OSes.
- [Libre Hardware Monitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) - full real-time hardware monitoring
- [Netscanner](https://github.com/Chleba/netscanner) - A network scanner and diagnostic tool in the terminal with a modern TUI: ARP scan, ping, packet analysis, OUI lookup, Wi-Fi diagnostics. Rust.
- [NtWarden](https://github.com/mrT4ntr4/NtWarden) - program for Windows that shows what is really going on inside the system "under the hood": which processes are running, which drivers are loaded, which network connections are open, etc.
- [OpenHardwareMonitor](https://github.com/HardwareMonitor/OpenHardwareMonitor) - free open-source program for Windows. Shows the temperature of the processor, graphics card, hard drives, fan speeds and voltages in real time
- [SigDigger](https://github.com/BatchDrake/SigDigger) - digital analyzer with a graphical interface, designed for analyzing and decoding unknown radio signals
- [System Informer](https://github.com/winsiderss/systeminformer) - powerful task manager for Windows. Shows processes, network connections, CPU/memory load in much more detail than the standard task manager. Useful for finding suspicious processes

- [LinuxPlay](https://github.com/Techlm77/LinuxPlay) - This is a remote access program: you connect from your Windows computer to a Linux one, with the screen, sound and mouse transmitted with minimal latency, as for network gaming.
- [TigerVNC](https://github.com/TigerVNC/tigervnc/releases/tag/v1.16.2) - Classic VNC server for Linux remote desktop

## Traffic & Firewall
- [Ad Guard Home](https://github.com/AdguardTeam/Adguardhome) - Ad blocking at the provider level
- [Cloudflare Diagnostics](https://try.cloudflare.com/) - Online network diagnostics from Cloudflare: traceroute by AS, DNS resolution, port checks, WARP status — in the browser with no installation.
- [DNS Server](https://github.com/TechnitiumSoftware/DnsServer) - network-wide ad blocking + protection from ISP tracking
- [DPI Checkers](https://github.com/hyperion-cs/dpi-checkers) - checking whether an internet provider blocks sites
- [firewalld](https://firewalld.org/) - Linux firewall daemon with zones and D-Bus API, frontend for nftables; default in Fedora/RHEL; free, GPL.
- [Glasswire](https://www.glasswire.com/) - network monitoring
- [Gufw](https://gufw.org/) - Graphical firewall UI for ufw on Ubuntu/desktop Linux; free, GPL.
- [Libreswan](https://libreswan.org/) - IPsec implementation for Linux, fork of Openswan/FreeS/WAN, IKEv2; free, GPL.
- [MyIP](https://github.com/jason5ng32/myip) - everything about your IP in one window: address, geo, DNS, WebRTC leaks, speed and access to services
- [nftables](https://netfilter.org/projects/nftables/) - Linux kernel packet filtering framework replacing iptables: tables, chains, sets; free, GPL.
- [OpenSnitch](https://github.com/evilsocket/opensnitch) - Interactive application firewall for Linux (eBPF): per-connection allow/deny prompts; GPL-3.0.
- [OpenVPN](https://openvpn.net/) - Mature TLS VPN client/server; Access Server paid, Community Edition free; core OSS under GPL.
- [oproxy](https://github.com/sauravrao637/oproxy) - local proxy tool for developers: it intercepts HTTP/HTTPS/SOCKS5 traffic, shows requests and responses, and lets you replace or edit them (mocks, delays, redirects)
- [PortCheck](https://github.com/JamiKettunen/PortCheck) - Simple Windows GUI to check IPv4 TCP ports on a host: editable target IP, adjustable timeout with F1-F4 hotkeys, single exe; C# WinForms; MIT.
- [ProxyBridge](https://github.com/InterceptSuite/ProxyBridge) - An open-source analog of Proxifier in C: redirects any TCP/UDP traffic on Windows/macOS/Linux into an HTTP/SOCKS5 proxy. Forces any applications through a proxy.
- [Shadowsocks for Windows](https://github.com/shadowsocks/shadowsocks-windows) - Classic SOCKS5 proxy client for bypassing blocks: encrypted traffic, server configs, QR import. Open-source C#.
- [Simple Wall](https://github.com/henrypp/simplewall) - Blocking internet access for specific sites
- [Sniffnet](https://github.com/GyulyVGC/sniffnet) - complete monitoring of my computer's network traffic
- [SoftEther VPN](https://www.softether.org/) - Multi-protocol VPN server: SSL-VPN, L2TP, OpenVPN clones; university project; free, Apache-2.0.
- [SpoofDPI](https://github.com/xvzc/spoofdpi) - A simple and fast anti-censorship tool in Go: bypasses providers' DPI (deep packet inspection) with a single binary.
- [strongSwan](https://www.strongswan.org/) - IPsec-based VPN solution for Linux with IKEv1/v2, EAP, PKI; free, GPL.
- [tcpdump](https://www.tcpdump.org/) - Classic CLI packet analyzer with libpcap filters; free, BSD.
- [ufw](https://launchpad.net/ufw) - Uncomplicated Firewall: simple CLI front-end for iptables/ufw frontends, default in Ubuntu; free, GPL.
- [VyOS](https://vyos.dev/) - Open-source network OS: routing, firewall, VPN on x86 and cloud; free rolling release plus paid LTS; GPL.
- [WireGuard](https://www.wireguard.com/) - Modern fast VPN with small codebase and cryptokey routing; in-kernel since Linux 5.6; free, GPL/MIT mix.
- [Wireshark](https://github.com/wireshark/wireshark) - Standard network traffic analyzer: deep dissection of hundreds of protocols, live capture, filters, follow stream. Detail view of any packet.

## Wi-Fi
- [AtEar](https://github.com/NORMA-Inc/AtEar) - A Wi-Fi auditing framework: cracking wireless networks, vulnerability analysis and pentesting. JavaScript, tuned for wireless security.
- [MyPublicWiFi](https://mypublicwifi.com/publicwifi/en/index.html) - program for Windows that turns an ordinary computer into a Wi-Fi router (access point)
- [OpenWrt](https://github.com/openwrt/openwrt) - Linux firmware for routers: replaces the stock firmware with a full Linux with packages, VPN, firewall and fine network tuning.
- [WiFiSpace](https://wifispc.com/) - a map of Wi-Fi points with passwords around the world, added by users
